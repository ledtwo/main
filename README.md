# main — 个人主页静态模板

Personal homepage static template / 个人主页静态模板。

## 页面

- `index.html` — 主页（含个人简介、作品展示、联系区块）
- `loveTree.html` — 动态爱心树页面（配 `love.mp3` 背景音乐）
- `404.html` — 404 页面

## 目录结构

- `css/` `css2/` `scss/` — 样式文件
- `js/` `js2/` — 脚本文件
- `img/` — 图片资源
- `Love_files/` — 爱心树页面资源

## 使用

纯静态页面，直接用浏览器打开 `index.html`，或部署到任意静态托管（GitHub Pages / Nginx 等）。

## Pages

- `index.html` — homepage (bio, works, contact)
- `loveTree.html` — animated love-tree page with background music
- `404.html` — not-found page

Open `index.html` in a browser, or deploy to any static hosting.
